# TUI Architecture Verification — Plan v2

## Objective
Verify whether the TUI duplication issue actually exists, and if so, fix it.

## Problem Analysis
- `src/tui-api.ts` (24 lines) is already a **facade** that re-exports from:
  - `./config.js` (loadConfig, findConfigFiles, saveConfig, ConfigLocation)
  - `./tui-helpers.js` (getHealthBadge, getHealthStatusText, getHealthSummary)
  - `./health-registry.js` (HealthRegistry)
  - `./agent-metadata.js` (getAgentMetadata)
- `.opencode/tui/agent-manager.jsx` — the TUI JSX plugin (may import from `dist/tui-api.js`)
- **Key question**: Does the JSX file already use the facade, or does it duplicate logic inline?

## Implementation Plan

- [ ] Read `.opencode/tui/agent-manager.jsx` and check imports
- [ ] If JSX file imports from `dist/tui-api.js` or `../dist/tui-api.js`:
  - No duplication issue — mark as resolved
  - Check for any inline helper functions that could be moved to `tui-helpers.ts`
- [ ] If JSX file has inline duplicated logic (e.g., health badge rendering, config loading):
  - Identify each duplicated function
  - Move to `src/tui-helpers.ts` if not already there
  - Update JSX file to import from `dist/tui-helpers.js`
  - Write tests for moved functions in `tui-helpers.ts`
- [ ] Verify JSX file does NOT export `server` (only `tui`) — per anti-pattern rules
- [ ] Run `bun test` — all pass
- [ ] Run `bun run build` + `bun run deploy-plugin` — verify TUI still works

## Verification Criteria
- [ ] Confirmed: TUI JSX file uses shared facade (no significant duplication)
- [ ] OR: Duplicated logic moved to shared modules and imported
- [ ] TUI plugin exports only `tui`, not `server`
- [ ] All tests pass

## Risks
1. **JSX file may import from wrong path**: If JSX imports from `../dist/tui-api.js`
   but the dist is not built, TUI breaks at runtime. Mitigation: verify import path
   works with the build output structure.
2. **SolidJS compatibility**: Imports in JSX must be compatible with SolidJS runtime.
   Mitigation: `tui-api.ts` only exports data/functions, no React/Solid dependencies.
