# OpenCode Knowledge Harvest

This repository contains harvested knowledge from OpenCode sessions, organized into reusable patterns, techniques, and insights.

## Structure

- `skills/` - Reusable patterns and techniques
- `lost-ideas/` - User-discussed concepts that were never built
- `mistakes/` - Errors, wrong approaches, or costly detours
- `partial-systems/` - User-discussed architectures/systems that were partial or abandoned
- `commands/` - Repeated multi-step workflows that should become slash commands
- `tools/` - Programmatic logic that should become custom tools
- `session-map.md` - Full index: session_id → project → findings
- `.mining-ledger.json` - Session-level memory
- `.findings-registry.json` - Finding-level memory
- `.harvest-runs.json` - Run-level memory
